# 🎓 AI Campus Assistant

An AI-powered college document assistant that helps students quickly find and understand information from their college documents.

## 🚀 Features

- 💬 Ask questions about college documents
- 📝 Generate study notes
- ❓ Generate quizzes
- 🎯 Find important exam topics
- 📚 Create a study plan
- 📄 Read information from PDF documents
- 🤖 AI-powered answers using Google Gemini
- 💾 Chat history
- 📊 Document status and statistics
- 🎓 Simple and student-friendly interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- PyPDF
- Python-dotenv
